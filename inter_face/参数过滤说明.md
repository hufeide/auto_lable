# 参数过滤功能说明

## 问题

当使用共享参数时，所有共享参数会传递给每个任务。如果某个脚本不需要某些参数，会报错：
```
error: unrecognized arguments: --api_url xxx --LS_URL xxx
```

## 解决方案

有两种方案可以解决这个问题：

### 方案1：在脚本中添加所有可能的参数（简单）

在每个脚本的 argparse 中添加所有共享参数，即使不使用：

```python
def main():
    parser = argparse.ArgumentParser(description='你的脚本')
    
    # 本脚本需要的参数
    parser.add_argument('--exam_id', type=str, required=True, help='考试ID')
    parser.add_argument('--subject_id', type=str, required=True, help='科目ID')
    
    # 其他共享参数（可选，避免报错）
    parser.add_argument('--api_url', type=str, help='API地址（本脚本不使用）')
    parser.add_argument('--storage_title', type=str, help='存储标题（本脚本不使用）')
    parser.add_argument('--LS_URL', type=str, help='Label Studio URL（本脚本不使用）')
    parser.add_argument('--output_directory', type=str, help='输出目录（本脚本不使用）')
    
    args = parser.parse_args()
    
    # 只使用需要的参数
    print(f"考试ID: {args.exam_id}")
    print(f"科目ID: {args.subject_id}")
```

### 方案2：使用参数过滤（推荐）

在 config.json 中为每个任务指定 `use_shared_params` 字段，只传递需要的共享参数：

```json
{
  "shared_params": {
    "exam_id": "475",
    "subject_id": "2119",
    "question_num": "24",
    "output_directory": "/path/to/output",
    "api_url": "http://192.168.1.210:9009/v1/chat/completions",
    "storage_title": "recoginse_20251120",
    "LS_URL": "http://localhost:5002"
  },
  "tasks": [
    {
      "id": "task1",
      "name": "错误数据查询",
      "script": "export_sql_step1.py",
      "script_type": "python",
      "params": {},
      "use_shared_params": ["exam_id", "subject_id", "question_num"],
      "next_task": "task2"
    },
    {
      "id": "task2",
      "name": "qwen3vl推理",
      "script": "infer_step2.py",
      "script_type": "python",
      "params": {},
      "use_shared_params": ["output_directory", "api_url"],
      "next_task": null
    }
  ]
}
```

#### 参数过滤规则

- 如果指定了 `use_shared_params`：只传递列表中的共享参数
- 如果没有指定 `use_shared_params`：传递所有共享参数（向后兼容）
- 任务的 `params` 会覆盖同名的共享参数

#### 示例

**任务1配置：**
```json
{
  "use_shared_params": ["exam_id", "subject_id"],
  "params": {}
}
```

**实际传递的参数：**
```bash
python script.py --exam_id 475 --subject_id 2119
```

**任务2配置：**
```json
{
  "use_shared_params": ["output_directory"],
  "params": {
    "custom_param": "value"
  }
}
```

**实际传递的参数：**
```bash
python script.py --output_directory /path/to/output --custom_param value
```

## 推荐做法

1. **使用参数过滤（方案2）**：更清晰，每个任务明确声明需要哪些参数
2. **脚本只定义需要的参数**：保持脚本简洁

## 迁移指南

### 从旧配置迁移

**旧配置（所有共享参数都传递）：**
```json
{
  "tasks": [
    {
      "id": "task1",
      "params": {}
    }
  ]
}
```

**新配置（只传递需要的参数）：**
```json
{
  "tasks": [
    {
      "id": "task1",
      "params": {},
      "use_shared_params": ["exam_id", "subject_id"]
    }
  ]
}
```

### 如何确定需要哪些参数

查看脚本的 argparse 定义：
```python
parser.add_argument('--exam_id', ...)      # 需要 exam_id
parser.add_argument('--subject_id', ...)   # 需要 subject_id
parser.add_argument('--question_num', ...) # 需要 question_num
```

在 `use_shared_params` 中列出这些参数名即可。

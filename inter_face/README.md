# Python 程序执行界面

一个基于 Flask 的 Web 界面，用于配置和运行 Python 程序。

## 功能特性

✅ **按钮式执行**: 点击按钮运行配置好的 Python 程序  
✅ **参数配置**: 为每个程序配置独立的运行参数  
✅ **参数共享**: 在多个程序间共享参数  
✅ **任务链**: 一个任务完成后自动提示运行下一个任务  
✅ **实时状态**: 实时显示任务运行状态和输出  
✅ **配置管理**: 通过 JSON 文件管理任务配置  

## 安装依赖

```bash
pip install -r requirements.txt
```

## 启动服务

```bash
python app.py
```

然后在浏览器中访问: http://localhost:5000

## 配置说明

编辑 `config.json` 文件来配置你的任务:

```json
{
  "tasks": [
    {
      "id": "task1",
      "name": "任务名称",
      "script": "脚本路径.py",
      "params": {
        "参数名": "参数值"
      },
      "next_task": "下一个任务的id（可选）"
    }
  ]
}
```

## 使用说明

1. **添加共享参数**: 在顶部输入参数名和值，点击"添加参数"
2. **运行任务**: 点击任务卡片上的"运行任务"按钮
3. **查看输出**: 任务完成后会显示输出结果
4. **任务链执行**: 如果配置了 next_task，完成后会提示运行下一个任务

## 示例脚本

项目包含三个示例脚本:
- `example_script1.py`: 数据预处理
- `example_script2.py`: 数据分析
- `example_script3.py`: 生成报告

你可以替换为自己的 Python 脚本。

## 注意事项

- 脚本路径相对于 `inter_face` 目录
- 脚本需要支持命令行参数（使用 argparse）
- 共享参数会自动合并到每个任务的参数中

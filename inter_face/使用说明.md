# 使用说明

## ✅ 服务已成功启动！

服务正在运行在: **http://localhost:5001**

## 🚀 快速开始

### 1. 访问界面
在浏览器中打开: http://localhost:5001

### 2. 使用界面

#### 添加共享参数（可选）
- 在顶部"共享参数"区域输入参数名和值
- 点击"添加参数"按钮
- 共享参数会自动应用到所有任务

#### 运行任务
- 点击任务卡片上的"运行任务"按钮
- 查看实时状态和输出结果
- 如果配置了下一个任务，完成后会自动提示

### 3. 配置你自己的任务

编辑 `config.json` 文件：

```json
{
  "tasks": [
    {
      "id": "task1",
      "name": "任务名称",
      "script": "/完整/路径/到/脚本.py",
      "script_type": "python",
      "params": {
        "参数名1": "参数值1",
        "参数名2": "参数值2"
      },
      "next_task": "task2"
    }
  ]
}
```

#### 支持的脚本类型

**Python 脚本** (`script_type: "python"`)
- 使用 argparse 接收参数
- 示例: `test_script1.py`

**Bash 脚本** (`script_type: "bash"`)
- 通过环境变量接收参数（大写）
- 示例: `../example_script.sh`

## 📝 Python 脚本模板

```python
#!/usr/bin/env python3
import argparse

def main():
    parser = argparse.ArgumentParser()
    parser.add_argument('--param1', type=str, help='参数1')
    parser.add_argument('--param2', type=str, help='参数2')
    args = parser.parse_args()
    
    print(f"参数1: {args.param1}")
    print(f"参数2: {args.param2}")
    
    # 你的代码逻辑
    
    return 0

if __name__ == '__main__':
    import sys
    sys.exit(main())
```

## 📝 Bash 脚本模板

```bash
#!/bin/bash

# 通过环境变量获取参数（大写）
echo "参数1: $PARAM1"
echo "参数2: $PARAM2"

# 你的代码逻辑

exit 0
```

## 🔧 测试 API

访问测试页面: http://localhost:5001/test

或使用 curl 命令：

```bash
# 运行任务
curl -X POST http://localhost:5001/api/run_task \
  -H "Content-Type: application/json" \
  -d '{
    "task_id": "test1",
    "script": "test_script1.py",
    "params": {"exam_id": "123"},
    "script_type": "python"
  }'

# 查看状态
curl http://localhost:5001/api/task_status/test1

# 设置共享参数
curl -X POST http://localhost:5001/api/shared_params \
  -H "Content-Type: application/json" \
  -d '{"param_name": "param_value"}'
```

## ⚠️ 注意事项

1. **脚本路径**: 使用绝对路径或相对于 `inter_face` 目录的路径
2. **Python 脚本**: 必须使用 argparse 接收参数
3. **Bash 脚本**: 参数通过环境变量传递（自动转为大写）
4. **端口占用**: 如果 5001 端口被占用，修改 `app.py` 中的端口号

## 🐛 故障排查

如果点击按钮没反应：

1. **检查浏览器控制台** (F12 → Console)
2. **查看服务器日志** (运行 Flask 的终端窗口)
3. **测试 API** (访问 http://localhost:5001/test)
4. **手动运行脚本** 确保脚本本身没问题

详细排查步骤见: `TROUBLESHOOTING.md`

# 共享参数使用说明

## 工作原理

共享参数会**自动合并**到每个任务的参数中。当运行任务时：
1. 系统先读取共享参数
2. 再读取任务特定参数
3. 任务参数会覆盖同名的共享参数
4. 合并后的参数传递给脚本

## 配置示例

```json

      "id": "task1",
```

## Python 脚本写法

### ✅ 正确写法

```python
#!/usr/bin/env python3
import argparse
import sys

def main():
    parser = argparse.ArgumentParser(description='你的脚本描述')
    
    # 定义所有可能接收的参数
    parser.add_argument('--exam_id', type=str, required=True, help='考试ID')
    parser.add_argument('--subject_id', type=str, required=True, help='科目ID')
    parser.add_argument('--question_num', type=str, help='题号')
    parser.add_argument('--output_directory', type=str, required=True, help='输出目录')
    parser.add_argument('--storage_title', type=str, help='存储标题')
    
    args = parser.parse_args()
    
    print(f"考试ID: {args.exam_id}")
    print(f"科目ID: {args.subject_id}")
    print(f"题号: {args.question_num}")
    print(f"输出目录: {args.output_directory}")
    
    # 你的代码逻辑
    
    return 0

if __name__ == '__main__':
    sys.exit(main())
```

### ❌ 错误写法

```python
# 错误1: default 值使用了 f-string 但没有变量
parser.add_argument('--storage_title', type=str, default=f"recongnise{}", help='...')
# 应该改为：
parser.add_argument('--storage_title', type=str, default="recongnise", help='...')

# 错误2: 参数名不匹配
parser.add_argument('--storage_title', ...)
# 但使用时：
run(args.output_directory)  # 应该是 args.storage_title

# 错误3: 没有定义参数但期望接收
# 如果共享参数中有 exam_id，但脚本中没有定义，会报错
```

## 修复你的脚本

### 原代码（错误）：
```python
parser = argparse.ArgumentParser(description='Step 3: 从数据库导出错误数据')
parser.add_argument('--storage_title', type=str, default=f"recongnise{}", help='输出目录')
args = parser.parse_args()

run(args.output_directory)  # ❌ 参数名不匹配
```

### 修复后（正确）：
```python
parser = argparse.ArgumentParser(description='Step 3: Label Studio 库生成')

# 定义所有需要的参数
parser.add_argument('--storage_title', type=str, required=True, help='存储标题')
parser.add_argument('--output_directory', type=str, required=True, help='输出目录')
parser.add_argument('--exam_id', type=str, help='考试ID（可选）')
parser.add_argument('--subject_id', type=str, help='科目ID（可选）')

args = parser.parse_args()

print(f"存储标题: {args.storage_title}")
print(f"输出目录: {args.output_directory}")

# 使用正确的参数名
run(args.storage_title, args.output_directory)
```

## 在界面中使用

### 1. 配置共享参数
在界面顶部点击"编辑"按钮，添加或修改共享参数：
- exam_id: 475
- subject_id: 2119
- output_directory: /home/aixz/data/result

### 2. 配置任务参数
每个任务可以有自己的参数，会自动合并共享参数。

### 3. 运行任务
点击"运行任务"按钮，系统会：
1. 合并共享参数和任务参数
2. 转换为命令行参数：`--exam_id 475 --subject_id 2119 ...`
3. 执行脚本

## 常见问题

### Q: 共享参数没有生效？
A: 检查参数名是否完全匹配（大小写敏感）

### Q: 脚本报错 "unrecognized arguments"？
A: 脚本中没有定义该参数，需要添加 `parser.add_argument()`

### Q: 如何让某个参数可选？
A: 不要设置 `required=True`，并提供 `default` 值

### Q: 如何覆盖共享参数？
A: 在任务的 params 中设置同名参数即可
